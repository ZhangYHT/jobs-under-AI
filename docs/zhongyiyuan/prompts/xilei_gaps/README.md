# 查漏补缺提示词(把各模型上一轮偷懒/截断漏掉的细类补齐)

上一轮许多非深度研究模式的模型只输出一部分就停下等「继续」。这里按模型汇总它们漏掉的细类,
用强化版「一次性完整输出」提示词重新投喂。强调:禁止「继续」、一口气写全。

结构:`xilei_gaps/<模型>/g01.md ...`。每个模型把自己目录下的每条投喂给它本人,回复存为 `<模型>.txt` 再跑 `tools/parse_xilei.py`(按编码自动并入,不会覆盖已有)。
