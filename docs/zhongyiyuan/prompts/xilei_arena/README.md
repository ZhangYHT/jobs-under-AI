# Arena 双盲补充数据(lmarena 随机对战)

把 `xilei_arena/大类N/aNN.md` 丢进 lmarena 的匿名对战,一次能收到**两个匿名模型**的打分,作为补充低权重票(每票约0.80)。
提示词已做成自包含中性版(不依赖模型身份),并强化「一次性完整输出」。

## 回收
两个回复分别存为 `arena1.txt`/`arena2.txt`(或 `arena3`...,序号区分不同对战),放进一个目录跑 `tools/parse_xilei.py`;
解析器已把 `arena+数字` 当作独立模型键保留,聚合时按 arena 低权重取平均并入。别忘了十三大主流模型仍是主力。
