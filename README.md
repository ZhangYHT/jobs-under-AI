# jobs-under-AI · AI 时代各岗位冲击图谱(中国版)

一个交互式可视化:用**官方职业分类**为地基,用自创的**「AI 众议院」**(多个中外大模型集成)评估 AI 对各岗位的冲击,并展示模型间分歧度。灵感来自 [karpathy/jobs](https://github.com/karpathy/jobs) 与其中文改编 madeye/jobs,但在两点上做了实质升级:**分类与统计锚定官方来源**(而非 AI 凭空生成),**冲击分由多模型集成**(而非单一模型)。

## 它长什么样
- 分层树状图(treemap):面积 = 就业人数,颜色 = 选定维度(0–100)。
- 概览 大类(8)→ 中类(79);点击中类缩放钻取到官方**细类**(具体职业)。
- 6 个维度:综合冲击 · 任务自动化 · AI增强 · 数字化程度 · 人际物理监管护城河 · 落地速度。
- 详情面板:六维雷达、各模型打分、就业/薪资/学历及来源、官方数字职业(S)/绿色职业(L)标注、数据 flag。
- 顶部汇总:六维雷达、冲击分布直方图、就业分层环形图。
- 模型分歧上色、搜索、深浅色(跟随设备)、缩放与悬停动画。

预览:打开 `site/index.html`(纯 HTML + Canvas,零依赖、无构建)。

## 数据怎么来(AI 众议院,四步两模式)
| 步骤 | 内容 | 模式 | 来源 |
|---|---|---|---|
| 1 | 职业分类校验与扩源 | 考据(官方锚定) | 职业分类大典 2022 |
| 2 | 就业人数 | 考据(官方锚定) | 七普 / 人口普查年鉴-2020 等 |
| 3 | 薪资 + 学历 | 考据(官方锚定) | 国家统计局分行业工资 / 大典 |
| 4 | AI 冲击 6 维打分 | 评审(11 模型集成) | 统一评分细则 |

指令见 [`docs/zhongyiyuan/`](docs/zhongyiyuan);数据规范见 [`docs/data-spec.md`](docs/data-spec.md)。

## 目录
```
data/occupations.cn.json     官方分类骨架(8大类/79中类/1639细类 + S/L 标注)
data/collected/step*/        各模型采集的原始 JSON(现含 claude 种子)
data/aggregated.cn.json      聚合成品(站点读取)
data/qa_report.md            人工复核工作单
aggregate.py                 归并(官方锚定)+ 聚合(集成)+ QA;并刷新 site/data.cn.js
site/index.html              可视化站点
docs/                        众议院指令 + 数据规范
prototype.html               Phase 0 原型(演示数据,留作参考)
```

## 用法
```bash
# 1) 把众议院各模型产出的 JSON 放进 data/collected/step*/<model>.json
# 2) 聚合并刷新站点数据
python aggregate.py
# 3) 打开站点
#    直接双击 site/index.html,或
python -m http.server   # 然后访问 /site/
```
